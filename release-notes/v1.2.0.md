## LiteTorrent 1.2.0

One self-contained `litetorrent.exe` for Windows 10/11 x64 — unpack and run.

**What's new**
- **Opens `.torrent` files and `magnet:` links**, if you want: asked once on the first start, switchable under **More**. If another program already owns them, Windows won't let any app take over silently — LiteTorrent says so and offers to open Settings → Default apps.
- **Files** button: choose which files of a torrent to download.
- **More** menu: download and upload speed limits, shown in the status bar when active.
- Fixed a possible crash around the "already in the list" message.
- This release was built by GitHub Actions straight from the tagged commit (link and SHA-256 below).

**Known limits:** files can only be downloaded or skipped (no priorities); speed limits are presets; the exe is not code-signed (SmartScreen will warn). Tested by hand on Windows. Details in the README and CHANGELOG.

---

**Что нового**
- **Открывает файлы `.torrent` и ссылки `magnet:`**, если вы хотите: вопрос один раз при первом запуске, переключается в меню **Ещё**. Если их уже открывает другая программа, Windows не даёт перехватить это молча — LiteTorrent сообщит и предложит открыть «Параметры → Приложения по умолчанию».
- Кнопка **Файлы**: выбор, какие файлы торрента скачивать.
- Меню **Ещё**: ограничение скорости загрузки и отдачи, видно в строке состояния.
- Исправлено возможное падение при сообщении «торрент уже в списке».
- Этот релиз собран GitHub Actions прямо из помеченного коммита (ссылка и SHA-256 ниже).

**Ограничения:** файлы можно только скачивать или пропускать (без приоритетов); ограничения скорости — готовые значения; exe не подписан (SmartScreen предупредит). Проверено вручную в Windows. Подробности — в README и CHANGELOG.
